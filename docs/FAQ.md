# 常见问题

## GitHub 项目需要密码吗

公开仓库可直接浏览和下载，不需要项目密码。部署后的应用有独立登录密码，保护你自己收集的直播资料。两个密码概念互不相同。

## 能用于公司直播运营吗

原始代码按 PolyForm Noncommercial 1.0.0 提供。商业场景需另行取得书面授权。请阅读 [许可证](../LICENSE) 并联系 [维护者](https://github.com/ewinhao-ops)。第三方服务还遵守各自条款。

## 装好后没有数据

这是空白安装的正常状态。可以先执行演示脚本，或自己建主播、知识库和直播场次。演示脚本会拒绝向已有业务数据的数据库混入样例。

## `/api/health` 正常，但 `/api/ready` 返回 503

前者表示服务运行，后者检查真实录制所需的依赖和配置。未设置模型 key、没有 FFmpeg 或 Chromium 都会导致 503。阅读返回的失败原因，补齐对应项目即可。通过检查仍不等于实际模型调用成功。

## 忘记管理员密码

停止服务，在自己的 `backend/.env` 中修改 `ACCESS_PASSWORD` 为至少 12 位的新密码，然后重启。旧管理员会话会失效。Docker 修改后运行 `docker compose up -d --force-recreate`。

## 登录后又回到登录页

本地 HTTP 不应设置 `COOKIE_SECURE=true`。确认浏览器地址和 `PUBLIC_BASE_URL` 一致，不要混用 localhost 与 127.0.0.1；公网部署请使用 HTTPS。没有自己的 Studio 平台时，保持 `AUTH_MODE=password`。

## 安装失败或命令找不到

新开一个终端，分别检查 Python、uv、FFmpeg。Linux 浏览器缺系统库时执行 `uv run --no-sync python -m playwright install --with-deps chromium`。不要通过复制别人的虚拟环境解决依赖问题，使用锁文件重新安装。

## 直播链接无法解析

先确认直播正在进行、链接有效且自己有权处理。平台页面、登录要求和反爬规则可能变化；需要时配置自己的 Cookie。就绪检查只检查本地依赖，不保证任意平台链接都可访问。

## 演示记录没有录像

演示脚本只写虚构文本，故意不附真实用户录像。用于测试页面与数据读取；不能据此判断模型效果或真实直播采集是否成功。

## 模型扣费和价格从哪里看

使用你自己填写的服务商账号。后台 token 记录与手填单价只提供部分估算，账单以服务商控制台为准。自动录制、情绪分析、深度报告和文档向量化等功能可能单独计费。

## 可以让所有人免登录看自己的后台吗

公开代码已经满足学习和下载需求。运行中的后台可能包含主播、客户与账号资料，请保留登录保护。公开演示请使用单独的虚构数据环境，不要拿业务数据库做免登录展示。
